# Tomoru 设计语言：夜灯

[English](design-system.md)

本文是设置窗口、菜单栏面板、首次引导和图片翻译卡片的设计规范。字幕层的外观由用户自己设置，不受这套规范约束。

## 方向

Tomoru 是「点亮字幕」的应用，名字是灯る，看板娘 Tomoru（ともる）抱着一盏纸灯，头顶坐着她的企鹅 ルビ（Rubi）。界面就是夜里的一张灯纸：

- **窗框是夜色**：靛蓝，来自吉祥物的头发。侧栏放在夜色上。
- **内容是纸面**：奶油色，来自她的卫衣。页面内容都在纸面上。
- **强调色是灯光**：琥珀，来自灯笼。只用在最重要的一个动作、选中状态和少量提示上。
- **字幕永远在夜空里**：预览字幕的「舞台」是深蓝底，配几颗星点和底部的暖光，和用户实际看到的字幕一致。

设计原则：

1. **先说状态，再给操作**。首页第一眼是「正在翻译」和停止按钮，然后才是各种设置。
2. **直白**。按钮写动作（开始翻译、停止翻译、改用 阿里云百炼），不用比喻（不写「熄灯」），不用用户要猜的图标。
3. **不重复**。一件事只在一个地方说。状态已经由按钮表达了，就不再另加标签；语言已经写在句子里了，舞台上就不再写。
4. **能直接改的就直接改**。首页那句「听 [Safari] 里的 [日语]，翻成 [中文]」可以直接点；不为了改一个值跳到另一页。
5. **会变多的东西要分层**。服务商、场景、记录都可能越来越多：先分组（本机 / 云端，按服务商，按日期），再列出；不做无限往下延伸的平铺列表。

## 规则

| 规则 | 做法 | 怎么保证 |
|---|---|---|
| 优先复用成熟库 | 交互行为一律用 MyGo `ui` 的 Base 组件（`ButtonBase`、`SwitchBase`、`SliderBase`、`SegmentedBase`、`TextInputBase`、`TextAreaBase`、`PopoverBase`、`ToastBase`、`TooltipBase`），它们负责键盘、焦点和读屏；外观由我们画。下拉菜单用系统原生菜单（`MenuButton`）。图标只用 Lucide，字体只用系统字体 | 不引入别的 UI 库、图标库或字体文件 |
| 组件源代码可控 | 所有视觉组件在 `internal/ui/kit`，一个组件一个文件，各自带 Tester 测试；`kit` 有一个组件展示测试，把每个组件的各种状态渲染成截图，评审时逐个看。MyGo 的问题提 PR 修上游 | 分层检查（`layers_test.go`）；页面只组合 `kit` 的组件 |
| 统一设计语言 | 颜色、字号、间距、圆角、阴影、动效都在 `kit/tokens.go` | `design_test.go`：`kit` 以外的界面代码里，不准出现 `ui.Hex` / `ui.RGB` / `ui.RGBA` / `ui.Oklch`，也不准给 `FontSize`、`Padding`、`Gap`、`Radius` 传数字字面量（0 除外）。例外只有字幕层（`overlay/`）和字幕绘制（`subtitle/subtitle.go`）：字幕的颜色、字号由用户设置 |
| 依赖要少（Few dependencies） | `go.mod` 的直接依赖只有 `mygo`、`x/sys`、云端识别用的 `coder/websocket`，以及 MyGo 本来就带的 `purego`、`x/image`、`x/text`。每种模式只有一个实现：一种按钮体系、一种提示条、一种对话框、一种卡片、一种空状态 | `design_test.go` 锁定 `go.mod` 的直接依赖清单，加依赖必须改测试，评审时一眼可见 |

### 间距、圆角、阴影

- **间距**：4 的倍数，`4 8 12 16 20 24 32`。卡片内边距 16–20，页面边距 30–32，卡片之间 14。
- **圆角**：
  - 胶囊和圆形按钮：取高度的一半；
  - 卡片：20；
  - 方块、列表项、选项行：16；
  - 输入框、分段控件：14；
  - 分段控件里的按钮、小图标底：8–11；
  - 纸面：14；
  - 窗框：18。
- **描边与阴影**：
  - 卡片只用 1 px 的 `Line` 描边，不加投影；
  - 选中状态用 2 px 的 `Lantern` 内描边；
  - 只有琥珀色的主要按钮带一圈暖色投影（`0 8 24 Lantern 45%`）。
- **暖光**：MyGo 没有径向渐变（只有线性和锥形）。舞台底部的光晕，用一个带大范围琥珀色阴影的椭圆来做。

### 动效

全部定义在 `kit/tokens.go`，其他地方不自己定时长。

- `Spring` 弹簧 460 ms（回弹 0.08）：位置变化，例如选中框在选项之间滑动。
- `Rise`：出现的东西在弹簧上淡入并上升 8 DIP，引导的每一步也是；一组里的东西相隔 40 ms 依次出现（`Rise(i)`）。不从侧面滑入。`Arrive` 是同样的入场，在元素第一次构建时播放，用于随容器一起出现的东西：每一步的各部分、窗口的第一帧、刚出现的面板里的文字。
- `Grow`（`Resize`，340 ms 无回弹弹簧）：面板随内容改变尺寸，过程中裁剪内容；新内容在 `Settle`（200 ms）后、面板差不多到位时才升入，文字不会碰到边框。
- `Fade` 200 ms：原地变化的颜色和状态（点亮、变暗）。`FadeQuick` 120 ms：先让旧的离开，新的再进来，两者不会叠在一起。
- 用户打开「减少动态效果」时，全部改成直接切换。

引导的识别、翻译两步，用一条时间线展示一句话的流向：光点从「听到的声音」流到识别，句子出现；光点再流到翻译，译文出现。当前步骤选的那块面板点亮：玻璃更亮、带琥珀色细边；其他面板只把内容调暗；换选引擎时对应面板闪一下。「体验一下」用同一组面板跑真实听到的内容，光点到达哪块面板，左边对应的检查才打勾。

舞台的星点和暖光都不动。

### 图标

- 只用 Lucide，线宽 2。
- 尺寸：侧栏 17、按钮里 13–16、引导权限行里 18。
- 图标从 Lucide 拷 SVG 到 `internal/ui/assets/icons/`，用到哪个拷哪个（许可见同目录的 `LICENSE`）。
- 只有图标的按钮必须有读屏文字（`Label`）和悬停提示（`Tooltip`）。
- app 图标是 Tomoru 从下沿探出头。`swift scripts/app-icon.swift <原画> <小尺寸原画>` 用看板娘原画生成 `assets/icon.png`、`icon-small.png` 和 `app/icon/Tomoru.icns`（`macos.icon`），32pt 及以下（含界面里的小图标）用同一张画的近景裁切。菜单栏面板顶栏是看板娘的贴纸（`assets/sticker.png`）：Tomoru 抬头看着头顶提灯笼的 ルビ，奶油色白边，背景抠成透明。不在翻译时两人都闭眼睡着（`sticker-asleep.png`），和菜单栏图标一样；两张之间淡入淡出。
- 菜单栏图标是 Tomoru 歪着头探出半张脸，头顶翘着呆毛：不在翻译时闭眼，翻译中睁眼。源文件是 `assets/tray-idle.svg`、`tray-on.svg`，`swift scripts/tray-icons.swift` 生成 PNG。
- 左键点它打开菜单栏面板（Tomoru 自己画的）；右键（macOS 上也可以按住 Control 点）弹出系统原生菜单，macOS 和 Windows 一样：开始或停止翻译、截图翻译（各自带快捷键），打开 Tomoru、关于 Tomoru，最后是退出 Tomoru。原生菜单只负责不打开面板就做一件事，或者退出；调节类的设置留在面板里，面板也能退出，给从不右键的人用。

## 页面

- 权限页一行一项，给了就打勾；右边是「你的隐私」：不录音、看不到你的屏幕（只翻译你自己截下的图）、记录只在这台电脑上。
- 快捷键先验证再试用：用户按下的键帽亮起（`KeyLit`），按对了左边显示「按对了」。验证期间快捷键被引导拿住（`core.Held`），不会开始翻译或框选。
- 中途退出或被系统重开，下次打开回到停下的那一步。

**图片翻译卡片**（`ui/imagecard/`）：浮在所有应用上面、不抢焦点的面板窗口，出现在框选区域下方（放不下就在上方），从剪贴板来的放在菜单栏图标旁；纸面圆角，高度按图片和四行译文算，用户拖动调整过就一直用记住的大小，译文出来时不改大小，在里面滚动；标题行、缩略图（点一下弹出单独的窗口，在屏幕中间按原来的大小显示完整原图，拖图片移动，点关闭按钮或按 Esc 关闭）、译文（出来之前是三条呼吸的占位线）、底部「由 Index-Translate 云端翻译」（名字是链接，悬停提示图片和译文都不保存）和「复制」。标题行右侧是目标语言的 `Picker`；没有图片时，卡片改为提示开启屏幕录制。见 [图片翻译](image-translation_zh.md)。

**字幕层**：悬停和调整位置时，字幕框和上方工具栏垫系统的 Liquid Glass（`overlay/glass_darwin.go`）：

- 用 AppKit 的 `NSGlassEffectView`（macOS 26），插在字幕层窗口里、MyGo 画面的下面，所以能透出后面别的应用。MyGo 的 glass 插件只能透出同一个窗口里画的东西。
- 用 clear 风格（regular 面积越大越磨砂）。底色变淡，只为让字看清：带底框 40%、沉浸式 27%；工具栏再深 12%。
- clear 玻璃只在活跃窗口里才透。用 AppKit 私有的 `_setForceMainAppearance:` 让字幕窗口一直显示为活跃，不抢焦点；系统没有这个方法时退回磨砂。macOS 大版本更新后要复查。
- 没有系统玻璃的平台（Windows、Linux）用半透明黑底和阴影。

工具栏：暂停或开始；场景和它的语言，点开是场景菜单（每个场景带语言）、原文语言和译文语言两个子菜单、交换语言、新建场景…（建好就切过去，并在场景页打开它来命名）、管理场景…（打开场景页，显示正在用的场景）；锁定、面板。场景排在语言前面：看的时候换节目比换语言多。字号在字幕样式里调，不放在这里。

## 文案

- 按钮写动作，标题写状态：「停止翻译」「正在翻译」「改用 阿里云百炼」。
- 说明最多一句，能删就删；能用数字说的用数字（12 个专名、1.2 GB）。
- 不用比喻和品牌化的说法代替功能名（不写「熄灯」「点亮」「听与译」）。
- 五种界面语言的文字都在 `locales/`，新文案同时补齐。按钮要在五种语言下都放得下（例如面板的「开始」和「停止」对称，不写「开始翻译」，否则旁边的运行数据会被挤成省略号）。

## 删除

删除先确认，删除后再给撤销。确认框是 `kit.Confirm`：问题、会一起删掉什么、取消（默认焦点）和红色的删除。专名表的单行删除不确认，只给撤销；本地模型删除后无法撤销，确认框会写明要重新下载多大。
